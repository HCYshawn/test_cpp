1. 顶层先设置最低 CMake 版本、项目名、项目版本和语言。

2. include(GNUInstallDirs) 引入标准安装目录变量，
   比如 bin、lib、include。
   include(CMakePackageConfigHelpers) 引入生成 CMake package 配置文件的工具。

3. 设置 C++17、要求标准必须满足，并开启 compile_commands.json 导出。

4. 设置构建产物输出目录：
   Windows 下 exe/dll 放 build/bin，
   lib/静态库/导入库放 build/lib，
   Linux/macOS 的 so/dylib 放 build/lib。

5. add_subdirectory(shape) 和 add_subdirectory(app)，
   把库子目录和示例 app 子目录加入当前构建。

6. 在 shape 子目录中收集 src/*.cpp，
   用 add_library(Shape SHARED ...) 创建动态库 target。

7. 给 Shape 设置 PUBLIC include 路径：
   源码树内构建时使用 shape/include，
   安装后使用安装前缀下的 include。

8. 给 Shape 自己定义 SHAPE_BUILDING_LIBRARY 宏，
   用于 Windows DLL 导出符号。
   这个宏只给 Shape 自己用，所以是 PRIVATE。

9. 设置 Shape target 的属性：
   VERSION 是完整版本，
   SOVERSION 是 ABI 主版本，
   OUTPUT_NAME 控制最终输出名为 shape。

10. install(TARGETS Shape ...) 安装动态库产物，
    并把 Shape 注册到 ShapeTargets 导出集合。
    Windows 下 dll 作为 RUNTIME 安装到 bin，
    lib 作为 ARCHIVE 安装到 lib，
    Linux/macOS 下 so/dylib 作为 LIBRARY 安装到 lib，
    INCLUDES 记录安装后的公共 include 目录。

11. install(DIRECTORY include/shape ...)
    真正把公共头文件安装到安装前缀的 include/shape 下。

12. install(EXPORT ShapeTargets ...)
    把 ShapeTargets 导出集合写成 ShapeTargets.cmake，
    并通过 NAMESPACE Shape:: 生成 Shape::Shape 这个 imported target。

13. configure_package_config_file 根据 ShapeConfig.cmake.in
    生成 ShapeConfig.cmake。
    这个文件是 find_package(Shape) 要加载的核心配置文件。

14. write_basic_package_version_file 生成 ShapeConfigVersion.cmake，
    用于 find_package(Shape 1.0 REQUIRED) 这种版本检查。

15. install(FILES ...)
    把 ShapeConfig.cmake 和 ShapeConfigVersion.cmake
    安装到 lib/cmake/Shape 下。

16. app 子目录中创建 shape_app 可执行程序，
    并 PRIVATE 链接当前构建树里的 Shape target，
    用于验证库项目内部能运行。
